# Notebook review — 21 November 2026

Reviewed `tp4a-pv-delaunay/parity_injection.ipynb` at notebook repository commit `e4b1a3d`. Cell numbers below are zero-based JSON cell indices. The original notebook has not been edited.

## Findings and changes

1. **Wrong periodic box in the final scan (cell 14).** `build_catalogue(..., L=1000)` is passed to `parity_stat` without `L`, so the latter defaults to 1 and applies modulo 1. This changes the catalogue and the triangulation. The new interface requires `L` and rejects out-of-box positions instead of silently folding them.

2. **Saved outputs and source disagree.** Cell 14 currently requests `A=[5,10,50,100]` and uses the generator's default `N=256`; its output lists amplitudes `0.001,...,0.032`. The saved numbers cannot establish the settings used to generate them. Every new run freezes code/configuration and saves each seed's measurements. The baseline explicitly selects `N=64`; the second run reproduces the current cell's `N=256` and amplitudes with the box fixed.

3. **The external DIVE dependency has an incompatible schema.** The public student repository was located at <https://github.com/josue-aubert/DIVE>. At the pinned revision in `vendor/sources.json`, its periodic branch computes normalized chirality but writes only `chi,l_min,l_mid,l_max`. The notebook expects `chi,chi_hat,l_min,l_mid,l_max`. The student's Mac executable may have been built from another source revision; this mismatch does not prove the saved notebook results used the wrong columns. A documented patch supplies the five-column schema and Python verifies the algebraic relationship between the columns.

4. **Periodic cells and ordering need explicit conventions.** DIVE's default iterator can return stored periodic copies in a 27-sheet representation. The patch requests `UNIQUE`, supported by [CGAL's periodic triangulation interface](https://doc.cgal.org/latest/Periodic_3_triangulation_3/classCGAL_1_1Periodic__3__triangulation__3.html). Equal distance scores do not define an invariant vertex ordering. Exactly tied cells receive zero parity weight and remain in the denominator; their count is recorded. For generic continuous catalogues there should be no ties. The sum of absolute signed volumes is checked on generic validation catalogues; for tied cells, zero parity weight means that this column no longer carries their geometric volume.

5. **Text precision and portability.** Absolute Mac paths were replaced by a project build and task-local temporary directories. The six-decimal rounding of input catalogues was removed, and DIVE output precision increased to 17 significant digits. This matters particularly for small `L=1` molecules. The schema and finite values are checked immediately. Field RNG state is local rather than global.

6. **Amplitude is a discrete mode-sum convention.** The notebook evaluates an unnormalised Fourier sum, with no volume/grid normalisation. Keeping its convention, the ensemble expectation is `E[|psi(x)|^2] = A * N_active_modes` before the response factor. Consequently changing resolution or the Fourier band changes the RMS at fixed A. Saved metadata includes both measured RMS and RMS divided by mean point spacing. A should not be interpreted as a physically normalised continuum displacement power spectrum without specifying a Fourier convention and units. [FINUFFT's interface](https://finufft.readthedocs.io/en/latest/python.html) confirms the type-2 sign and mode-order options used in the numerical regression check.

7. **The original symmetric null is an extreme-displacement case.** Cell 12 demonstrates `L=1, A=1.4e-9`, giving RMS/spacing about 0.3, but cell 13 switches to `L=1, A=1`. With about 137,000 modes, the latter has expected RMS/spacing of order 8,000. It still tests symmetry, but does not probe the same displacement regime. Both that original null and a controlled `L=1000,A=0.002` null are being rerun.

8. **Taking the real part does not, by itself, destroy helicity.** Away from unpaired Nyquist modes, the effective real-field Fourier coefficient is `F_real(k)=[F(k)+F*(-k)]/2`. Its helical covariance survives this projection. No additional Hermitian correction or amplitude rescaling is imposed. The new code agrees with the original function at several epsilon values when the original Nyquist convention is selected. For the baseline, the even-grid Nyquist planes are removed so all active modes have distinct opposite-wavevector partners for arbitrary-position evaluation. Spectral diagnostics verify zero longitudinal power and normalized helicities +1/-1.

9. **Positive controls require ensemble uncertainty.** Random molecule centres do not guarantee every molecule is isolated; the notebook already recovers slightly fewer than 2,500. Unrelated connecting cells are not proven to have zero expectation in a parity-asymmetric environment. We retain the identified molecule contribution, the remaining-cell mean, and injected handedness separately, and repeat each fraction over 20 seeds. The observed handedness fraction fluctuates about the requested probability; it is recorded rather than assumed exact.

10. **The statistical pass criteria were too strict.** A valid null occasionally exceeds two standard errors. Several statistics and amplitudes also create multiple comparisons. The CLT concerns the distribution of an appropriately normalized mean; it does not require the sample-standardized individual seed statistics to be exactly Gaussian. Summaries use between-seed scatter, SEM, approximate Student-t intervals, and paired differences for matching plus/minus seeds. Tetrahedra share points and must not be treated as independent samples. No null result is automatically failed solely for crossing two sigma.

## Physical interpretation

The generated field is transverse. Expanding mass conservation for `x=q+R*psi(q)` gives `delta=-R*div(psi)+O(R^2)`, so the leading density perturbation vanishes here. Detecting helicity in the final scalar point catalogue therefore depends on nonlinear structure and on the statistic's sensitivity. The field-helicity test establishes that helicity was injected; the molecule control establishes that the measurement can detect a chiral point arrangement. Neither guarantees a detectable mean tetrahedron chirality for every amplitude and spectral band.

A nondetection in these global means should lead to a calibrated study of tetrahedron size and shape, the occupied Fourier band relative to point spacing, and displacement strength. The saved tetrahedra enable this next analysis without regenerating catalogues. Any optimized weighting or selected bins should be assessed on independent validation seeds to avoid selecting noise.
